## 五个决定，以及被否掉的那条

### 1. PDF 只当锚点，不当内容

在 PDF 上选中一段，**不从 PDF 里抽文本**送给模型，只拿矩形去做 `synctex edit` 反查源码行，送过去的是**源码**。选中的字符串只作「可能不准」的附注。

否掉的是「让 AI 读 PDF 文字」：公式和连字抽出来是 `𝑥2` 这类乱码，模型会认真地基于乱码改错。代价是精度只能到行（`Column` 常为 `-1`），但**准的行**远胜**脏的字符**。

### 2. 反查坐标被缩了两次（`§B15`）

第一版选中第 3 行，反查回 `main.tex:6`（`\end{document}`）。做 y 扫描后才明白：`page.getViewport({scale:1})` 返回的**已经是点**（Letter = 612×792），代码又乘了 `72/96`，把 y 压到 0.75 倍，正好落进页眉空白。

教训不是「少乘一次」，是**这个错误不会报错**：`synctex edit` 对页外坐标照样返回一个最近的盒子。凡是「坐标 → 索引」的映射，都必须用一次扫描把整条轴的返回值打出来对，不能只看一个点对不对。

### 3. diff 的基准是「上一次编译」，不是磁盘上的文件

原来 `previousSource` 在每次编译成功后就被改写成当前内容，等于 `diff(x, x)`，`getDiff` **一直返回空**——因为这条路径当时没有 UI 在用，所以从没暴露。

现在两份快照都存**已编译**的内容：`previousSource`（上一版 PDF 对应的源码）与 `compiledSource`（当前 PDF 的），且只在内容真变化时推进。于是「连点两次编译」不会抹掉你正在看的高亮。

### 4. 色带不吃鼠标事件

`.diffLayer` 和所有色带 `pointer-events: none`。听起来是个样式细节，实际是取舍：**如果色带可点，恰好是「改动过的那几行」选不中文字**，正好废掉前一天刚做好的主交互。悬停说明与点击跳转改成在容器上按矩形命中测试（删除带只有 7px，纵向判定放宽到 8px）。

定位用百分比而不是像素：缩放自动跟随，不需要 resize 钩子。

### 5. 审核者必须是另一个 AI，而且是一次性调用

最初的实现是「自动接受 + 可撤回」，被一句话纠正：**自动审核 = 派一个独立 AI 审**。这个区别不是措辞，是权限模型——当前会话的 Agent 就是改文件的那个，让它审自己等于盖章，而且它审完还能接着改。

所以审核者是一次**一次性模型调用**（`services/reviewer.ts`）：自带 system prompt、无工具、无历史，只能答 `accept` / `reject`。

三个实现细节值得记：

- **路由从哪来**：`agent.session.requestHeader().config`（官方 `dsh-experimental-auto-review` 的取法）。但**新会话在首轮之前没有 header**，实测返回 undefined，所以回落到 `ctx.agentDefaultModel.currentSelection()`。
- **打不开闸门时不能放行**：解析失败、调用失败、25s 超时，一律判 `unavailable` → **转手动**（标记保留、提示「请点接受或撤销」）。默认通过是最坏的失败模式，因为它静默。
- **否决是有破坏性的**：`reject` 走的是和手动「撤销」同一个 `applyRevert()`，真的把源码写回去。所以按钮二次确认、审核有超时，且 system prompt 里把「什么算不可接受」写死（引入错误、删掉不该删的、留占位/TODO、顺手改无关部分）。

## 删除：从一道缝到两层

删除是唯一一种「新 PDF 里已经没有像素」的改动，画在那个 PDF 上永远画不出来。中间试过三代：

1. **2px 虚线缝** —— 太弱，扫一眼看不见。
2. **7px 红色斜纹带 + 左红边** —— 看得见了，但只说「这里少了一块」，不说少了什么。曾用实心粉底，读起来像「这行被改了」，**必须用斜纹**把两者区分开。
3. **两层**（`517aabe`）：覆盖层带上的被删源码（`DiffRegion.text`，8 行 × 200 字符）、右侧 `−N 行` 角标、悬停弹出等宽红色删除线文字；要真正排版效果就点 `对比`，用 latexdiff 合并两版重排一份第三版 PDF。

代价写在明处：`对比` 要多跑一次 tectonic，且 MiKTeX 的 `latexdiff.exe` 需要系统 Perl，这台机器没有——探针降级成「装 Perl」的可操作提示，不抛错。覆盖层那层不需要任何额外二进制，所以没有 Perl 也看得见删除。

## 两个「看起来没坏，其实在静默失败」的坑

- **删除接缝跑到页脚**。锚定「删除位置所在的新行」，在文档末尾时那行是 `\end{document}`，而 `synctex view` 对它返回的是**页码盒子**（y≈936），接缝就画在页面底部空白里，滚出视口后连 hover 都打不到。改为锚定**前一行、画在该行底部**。
- **`compiler.run()` 抛错时状态永远停在「正在编译」**。不是编译失败，是根本没起来；面板看起来像卡死。catch 后先 patch 成 `failed` 再抛。

## 真机验证（真实 tectonic + 真实模型调用，非 mock）

| 场景 | 结果 |
|---|---|
| 选中第 3 行 / 第 5 行 | 反查 `main.tex:3` / `:5`，逐行对得上 |
| 正文空白处拖框 | 浮条「第 1 页选区」，反查 `main.tex:5-6` |
| 改一行 + 插一行 | 2 条色带，对文字层垂直覆盖率 **0.88 / 0.82** |
| 只删一行（中段 / 文档末尾） | 接缝压在前一行文字下沿，tooltip 正常 |
| 自动审核 · 正常改动 | `自动审核通过：仅修改正文一行文字，语法无误…` |
| 自动审核 · 换成 TODO | `未通过，已回滚：…删除正文并加入 TODO 占位`，源文件确实被写回并重编 |
| 手动审核 | 出现「接受 2 / 撤销」，点接受后标记清零 |

## 还悬着的

- **latexdiff 要 Perl**：要么在文档里写清安装，要么放弃 `对比` 只保留覆盖层。目前是优雅降级。
- **否决即回滚是否太狠**：AI 判错就会写你的源文件。改成「保留改动 + 标红提示」是一行判断的事，但那样审核就只是建议。
- **字符级定位**：要自己做 LaTeX→文本映射，另一个量级，暂不做。
- **跨页选区**只反查当前页那一段。
- 审核的判定质量没有回归测试——只有两次真实调用的样本，不足以说它可靠。

## 一句话

这一天真正的产出不是三个功能，而是**把「谁的判断算数」这件事变成了可配置的**：改什么由你指，改得对不对由你、或另一个 AI、或没人来决定。
